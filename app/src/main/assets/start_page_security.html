보안 탭

완벽한 개인정보 보호 및 비공개 브라우징

보안 탭을 닫으면 다음 데이터가 절대 기기에 남지 않습니다:
  • 방문 기록 및 주소창 검색어가 기기에 저장되지 않습니다.
  • 쿠키 및 사이트 임시 데이터가 탭 종료 시 즉시 삭제됩니다.
  • 아이디, 비밀번호, 양식에 입력한 개인정보가 저장되지 않습니다.
방문하는 웹사이트나 인터넷 제공업체(ISP)의 네트워크 관리자에게는 사용자 활동이 보일 수 있습니다. 다운로드한 파일이나 추가한 북마크는 유지됩니다.
