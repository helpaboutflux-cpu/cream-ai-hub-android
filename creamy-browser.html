Features

브라우저가 지켜야 할 것부터
제대로 만들었습니다.

잠금, 금고, 동기화는 크리미 브라우저에서 가장 먼저 만든 기능입니다. 설정 깊숙한 곳이 아니라 화면 오른쪽 패널에서 바로 다룹니다.

닫는 순간 잠기고,
비밀번호로만 열립니다.

노트북을 잠시 두고 자리를 비워도 탭과 기록은 그대로 잠겨 있습니다. 잠금 화면은 테마와 함께 바뀌고, 틀린 비밀번호는 조용히 되돌아옵니다.

  • 비밀번호는 scrypt 해시로 이 PC에만 저장
  • 창을 닫거나 앱을 열 때 자동 잠금
  • 비밀번호를 잊으면 creamy-lock.json만 지우면 초기화

비밀번호는 사이트가 아니라
내 브라우저가 보관합니다.

Lemon Pass는 사이트별 아이디와 비밀번호를 금고에 넣고, 로그인 화면에서 골라 넣습니다. 암호화 키는 마스터 비밀번호에서 나오므로 서버에는 아무것도 남지 않습니다.

  • AES-256-GCM 암호화 금고, 잠금 해제는 세션 안에서만
  • 로그인 화면에서 항목 선택 → 자동 입력
  • 금고 파일은 동기화에 포함할지 직접 선택

한 번 연결하면
다른 PC에서도 이어집니다.

LK 계정으로 로그인하고 Google Drive를 연결하면 북마크·방문 기록·설정이 백업 폴더에 모입니다. 충돌은 항목 단위로 병합하고, 토큰과 금고 암호문은 이 PC의 파일에만 둡니다.

  • 북마크 · 방문 기록 · 설정 선택 동기화
  • Lemon Pass 금고는 켜야만 함께 올라감
  • 마지막 동기화 시각과 오류를 설정에서 바로 확인

광고와 트래커 도메인 목록을 브라우저가 직접 걸러 페이지를 가볍게 엽니다.

PORTABLE

무설치판
