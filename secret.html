1회용 자폭 보안 메모

브라우저 내부 Web Crypto API(AES-256-GCM)로 텍스트를 기기에서 직접 암호화합니다. 복호화 키는 링크 URL 해시에만 존재하여 서버에 평문이 전달되지 않습니다.

AES-256-GCM 종단간 암호화

전송 전 발신자의 브라우저에서 최고 수준 군사 등급 암호화가 이뤄져 중간 네트워크 탈취가 불가능합니다.

열람 후 자동 자폭

수신자가 복호화하여 내용을 읽는 즉시 메모리 및 브라우저 세션에서 자동 파기할 수 있습니다.

비밀번호 2중 잠금

원할 경우 PBKDF2 10만 회 해싱 기반의 2차 패스워드를 지정하여 링크 유출 시에도 안전합니다.
