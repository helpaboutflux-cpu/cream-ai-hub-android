로컬 모드 로그인 없음

프로젝트 연결

Project URL과 anon public key를 넣으면 로그인·동기화·짧은 공유 링크가 켜집니다. 비워두면 전부 로컬 모드로 동작합니다.

원격 저장(모든 방문자 반영)은 관리자 계정 로그인이 필요합니다. LK ID에서 로그인한 뒤 다시 시도하세요. SQL의 admin_users 에 같은 이메일이 등록되어 있어야 합니다. Google 로그인은 Supabase에서 제공자를 켠 뒤 사용할 수 있으므로, 지금은 이메일 로그인을 권장합니다.

데이터베이스 스키마

Supabase 대시보드 → SQL Editor 에 붙여넣고 실행하면 테이블 5개와 RLS 정책이 한 번에 만들어집니다. 여러 번 실행해도 안전합니다.
