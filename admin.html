API 사용 중지

켜면 oauth.html 에 들어오는 즉시 로그인·동의·코드 발급이 막히고 “현재 관리자에 의해 Soft Hub API가 일시 중지되었습니다.” 안내 화면이 뜹니다. 개발자 포털 API 대시보드 위에도 중지 배너가 표시됩니다.

로그인 화면 확인
지금 Soft Hub API가 중지되어 있습니다. 외부 도구의 LK 로그인·동의·코드 발급이 모두 막힙니다. 다시 켜면 즉시 복구됩니다.

OAuth 앱 관리

앱을 만든 본인은 승인 전에도 자기 계정으로 테스트할 수 있습니다. 다른 사용자에게 열려면 [공개 승인]이 필요하고, 문제가 있으면 [정지]로 즉시 모든 로그인과 API 호출을 막습니다.

아직 만든 OAuth 앱이 없습니다. 개발자 포털 → API 대시보드에서 앱을 만들면 여기에 나옵니다.

프로젝트 연결

Project URL과 anon public key를 넣으면 로그인과 짧은 공유 링크, 원격 설정이 켜집니다. 비워두면 전부 로컬 모드로 동작합니다.

원격 저장(모든 방문자 반영)은 관리자 계정 로그인이 필요합니다. LK ID에서 로그인한 뒤 다시 시도하세요. SQL의 admin_users 에 같은 이메일이 등록되어 있어야 합니다. Google 로그인은 Supabase에서 제공자를 켠 뒤 사용할 수 있으므로, 지금은 이메일 로그인을 권장합니다.

데이터베이스 스키마

Supabase 대시보드 → SQL Editor 에 붙여넣고 실행하면 테이블 8개(site_config · site_ads · shared_pages · admin_users · community_apps · tool_signals · oauth_clients · oauth_codes · oauth_reports)와 RLS 정책, LK 로그인 함수가 한 번에 만들어집니다. 여러 번 실행해도 안전합니다.
