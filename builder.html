섹션 블록 추가

클릭하면 지금 선택한 섹션 아래에 들어갑니다.

페이지 관리

페이지를 추가하고 이름·주소·순서를 바꿉니다. 첫 페이지가 홈이 됩니다.

주소(슬러그)는 페이지를 구분하는 값입니다(예: blog). 내비게이션 메뉴는 페이지가 2개 이상이면 자동으로 페이지 링크로 바뀝니다.

사이트 설정

공지 배너·빠른 문의·SEO·맨 위로 버튼을 설정합니다. 내보낸 사이트에 그대로 반영됩니다.

바로 게시

완성된 사이트를 무료 정적 호스팅(beacon.host)에 올리고 라이브 주소를 받습니다.

사이트 공유

링크 하나로 완성된 웹사이트가 열립니다. 로그인도 서버도 필요 없어요.

3분 사용법

클릭만으로 사이트를 만드는 순서

1
템플릿 또는 빈 캔버스홈에서 템플릿 7종 중 하나를 고르면 페이지·섹션·문구가 미리 채워집니다.
2
페이지 나누기내려가기 전에 페이지 바에서 홈·소개·블로그·문의처럼 페이지를 추가하세요. 내비게이션 메뉴가 페이지에 자동으로 연결됩니다.
3
섹션을 클릭해 고치기미리보기에서 섹션을 누르면 속성 패널이 열립니다. 글·버튼·색·이미지·글 목록·퀴즈 문항을 그 자리에서 바꾸고, 스타일 탭에서 등장 애니메이션을 고릅니다.
4
공지 배너 · 빠른 문의 · SEO사이트 설정에서 상단 고정 공지, 플로팅 문의 버튼, 제목·설명·파비콘을 정합니다. 사이트 애니메이션도 여기서 조절합니다.
5
바로 게시 · 통계 · 내보내기바로 게시로 라이브 주소를 받거나, 단일 index.html로 내려받아 어디든 올립니다. 통계 탭에서 방문·클릭·제출 기록과 사이트 진단 점수를 확인하세요.

모든 데이터는 이 브라우저(IndexedDB)에만 저장됩니다. 다른 기기로 옮길 때는 내보내기에서 JSON 백업을 받아 복원하세요.
