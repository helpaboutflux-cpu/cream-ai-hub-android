로그인부터 저장·공유·알림·테마까지, 그대로 가져다 쓰세요

Soft Hub가 계정과 저장소를 대신 맡습니다. 도구는 화면에만 집중하면 됩니다. 앱을 하나 만들면 Client ID가 발급되고, 아래 다섯 가지를 필요한 만큼 붙일 수 있습니다.

LK 계정 로그인

profile:basic

아이디·비밀번호를 직접 받지 않습니다. Soft Hub가 그린 동의 화면을 거쳐 고유 ID·닉네임·프로필 색상만 전달받습니다.

  • 회원가입 화면을 직접 만들지 않아도 됩니다
  • 비밀번호를 저장·관리할 책임이 없습니다

Flux Drive 저장소

drive:app

사용자의 Google Drive 안에 앱 전용 폴더(SoftHub_Apps/앱이름)만 열립니다. DB 없이도 결과물을 저장하고 다시 불러옵니다.

  • 15GB 저장 공간을 그대로 씁니다
  • 다른 앱 폴더와 내 드라이브 전체는 보이지 않습니다

짧은 공유 링크

share:create

만든 결과물을 go.html?id=... 짧은 주소로 만듭니다. 긴 주소를 복사해 보내지 않아도 되고, 링크를 아는 사람은 로그인 없이 엽니다.

  • 앱당 하루 40개까지
  • 만료일을 걸어 조용히 정리됩니다

알림 센터

push:send

도구가 사용자에게 알림을 보냅니다. 알림은 push-center.html에 쌓이고, 사용자는 앱별로 언제든 끌 수 있습니다.

  • 푸시 서버를 따로 두지 않아도 됩니다
  • 거부·차단 권한은 사용자에게 있습니다

테마 연동

theme:read

사용자가 고른 다크·라이트 설정과 브랜드 색을 읽어, 도구가 Soft Hub와 같은 모습으로 열립니다. 흰 화면이 어둡게 뜨는 어색함이 없습니다.

  • 색·모드만 읽고 개인정보는 읽지 않습니다
  • 한 줄로 사이트 전체와 톤을 맞춥니다
연동 예제 코드 보기 앱은 몇 분 안에 만들 수 있고, Client ID는 자동으로 발급됩니다.
등록 방법

도구 하나를 올리는 데 세 단계면 충분합니다

이름·한 줄 소개·아이콘만 정하면 카드 모양은 Soft Hub가 맞춰 그립니다.

  1. 01
    빌더에서 정보 채우기

    도구 이름, 한 줄 소개, 6가지 분류 중 하나, 도구 주소, 아이콘, 브랜드 컬러, 스크린샷까지. 옆의 미리보기를 보며 그 자리에서 고칩니다.

  2. 02
    제출하고 승인 기다리기

    주소·소개·스크린샷을 관리자가 확인합니다. 보통 하루 안에 끝나고, 반려되면 사유가 프로젝트 목록에 남습니다.

  3. 03
    발견 탭과 상세 페이지에 게시

    승인된 도구는 발견 탭의 분류 섹션과 전용 상세 페이지(tool.html?id=...)에 나옵니다. 조회·클릭·유용함 지표도 함께 쌓입니다.

전 세계 공개 · 0원

완전 무료로, 전 세계 사용자에게 알리세요

Soft Hub의 발견 탭은 로그인도 설치도 없이 열립니다. 등록비·심사비·광고비를 받지 않습니다.

  • 비용 0원 — 등록·게시·API·공유 전부 무료
  • 언어 제한 없음 — 한국어·영어 소개 모두 그대로 게시

LK 계정 로그인 API

앱을 만들고 Client ID를 받아 가세요

앱 하나에 Client ID 하나입니다. 허용한 Redirect URL로만 돌아오며, 승인 한 번에 일회용 code가 발급됩니다. 받은 code는 한 번만 쓸 수 있고 5분이 지나면 사라집니다. 만든 본인은 승인 전에도 바로 테스트할 수 있고, 다른 사용자에게 열려면 관리자 공개 승인이 필요합니다.

현재 관리자에 의해 새 앱 등록이 일시 중단되었습니다. 새 API 앱 만들기만 잠겼고, 이미 만든 앱의 설정·삭제는 그대로 됩니다.

내 OAuth 앱

외부 도구에 'LK 계정으로 로그인'을 붙일 때 쓰는 앱 목록입니다.
