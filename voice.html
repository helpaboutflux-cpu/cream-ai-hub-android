실시간 마이크 녹음뿐만 아니라 MP3, WAV, M4A 오디오 파일을 직접 업로드하여 브라우저 안에서 타임스탬프 텍스트로 변환합니다. 회의록, 강의, 마크다운 문서로 즉시 저장하세요.

마이크 & 파일 업로드 지원

실시간 음성 발화와 기기에 저장된 오디오 파일(MP3, WAV, M4A, WebM)을 모두 지원합니다.

실시간 파형 오디오 시각화

Web Audio API 기반 캔버스 주파수 분석기로 마이크 음량과 업로드된 오디오 파형을 시각화합니다.

타임스탬프 마크다운 내보내기

문장별 경과 시간 타임스탬프가 자동 기록되며 회의록 마크다운, 텍스트, 원본 오디오를 한 번에 저장합니다.
