6종 올인원 지원

앱에 필요한 안드로이드 시스템 권한만 선택하세요. 최소 권한 원칙으로 앱 용량이 줄고 사용자 신뢰를 높입니다.

웹 자바스크립트에서 window.WebToApk 객체로 안드로이드 네이티브 기능을 즉시 제어할 수 있습니다.

// 1. 네이티브 토스트 팝업 띄우기
if (window.WebToApk) {
  window.WebToApk.toast("작업이 완료되었습니다");
}

// 2. 햅틱 진동 울리기 (단위: ms)
window.WebToApk?.vibrate(50);

// 3. 네이티브 시스템 공유창 호출
window.WebToApk?.share({
  title: document.title,
  text: "공유할 설명 문구",
  url: window.location.href
});

// 4. 기기 정보 확인
const info = window.WebToApk?.getDeviceInfo();
console.log(info?.platform, info?.osVersion);

// 5. 앱 안전 종료
window.WebToApk?.exitApp();
우측 폰 미리보기에서 JS 브리지 탭을 누르면 실시간으로 인터랙션을 테스트할 수 있습니다.
앱 접속 감지용
